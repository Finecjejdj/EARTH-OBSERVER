# Развёртывание сайта «Земля 2016–2026»

## 1. HTTPS
- Netlify, Cloudflare Pages и GitHub Pages включают HTTPS сами. На GitHub Pages отметьте *Settings → Pages → Enforce HTTPS*.
- В коде нет ресурсов по `http://`. Единственное совпадение, `http://www.w3.org/2000/svg` в `style.css`, это имя пространства имён SVG, браузер его не запрашивает.
- Заголовок `Strict-Transport-Security` и директива CSP `upgrade-insecure-requests` уже добавлены.

## 2. Ключи
В `index.html`, `boot.js`, `globe.js`, `enhance.js`, `data.js` нет ни ключей, ни токенов, а погода и поиск города идут напрямую в Open-Meteo (ключ не нужен). Ничего секретного вшито не было. Если позже подключите платный API, ключ держите на сервере (функция Netlify/Cloudflare Worker как прокси), а не в файлах сайта.

## 3. three.js рядом с сайтом
1. Выполните `bash fetch-three.sh`. Он скачает `three.min.js` (r128) и сверит хеш с `boot.js`.
   Или скачайте файл вручную и положите рядом с `index.html`.
2. `boot.js` сначала берёт локальный файл. Если его нет, подключает CDN с `integrity` и `crossorigin`, и браузер отказывается выполнять подменённый файл.
3. Когда `three.min.js` лежит рядом, уберите `https://cdnjs.cloudflare.com` из `script-src` в `_headers` и в `<meta>` в `index.html`. Тогда CDN не нужен совсем.

## 4. Заголовки безопасности
Файл `_headers` работает на Netlify и Cloudflare Pages (положите в корень). CSP разрешает только:
- свой домен;
- `gibs.earthdata.nasa.gov` для снимка «за вчера» и живых облаков;
- `epic.gsfc.nasa.gov` для снимка Земли камерой EPIC;
- `earthquake.usgs.gov`, `www.seismicportal.eu` (EMSC, землетрясения Европы и Азии), `www.gdacs.org` (наводнения, циклоны, вулканы по всему миру), `geocoding-api.open-meteo.com` (поиск города), `eonet.gsfc.nasa.gov`, `api.open-meteo.com` и `archive-api.open-meteo.com` (архив погоды за прошлые месяцы) для живых данных (`live.js`);
- Google Fonts (стили и шрифты);
- `cdnjs.cloudflare.com` для запасной загрузки three.js (см. п. 3).

Дополнительно: `nosniff`, `X-Frame-Options`/`frame-ancestors` (запрет встраивания), `Referrer-Policy`, `Permissions-Policy`, `COOP`.
На GitHub Pages заголовки задать нельзя: там работает копия CSP из `<meta>` в `index.html` (без `frame-ancestors`).
Inline-стилей в разметке больше нет, поэтому `unsafe-inline` в CSP не нужен: политика не разрешает ни inline-скрипты, ни inline-стили.

## 5. Лимиты внешних сервисов
- **NASA GIBS** (снимок «за вчера»). Запрос идёт только когда посетитель включает переключатель, один раз за визит. Адрес зависит от даты, поэтому браузер кеширует картинку в течение дня. При большой посещаемости проверьте условия использования GIBS на сайте NASA Earthdata и при необходимости сохраните снимок на свой хостинг, обновляя его раз в сутки.
- **Google Fonts**. Лимитов на запросы практически нет, но это сторонний сервис. Чтобы полностью от него отказаться, скачайте шрифты Manrope и IBM Plex Mono, положите рядом и подключите через `@font-face`. После этого уберите Google из CSP.
- **USGS и NASA EONET** (землетрясения, события). Открытые каналы без ключа. Сайт опрашивает их раз в 5 и 15 минут, только пока вкладка открыта и слой включён.
- **Open-Meteo** (погода по нажатию). Один запрос на нажатие, результаты кешируются на 10 минут. Бесплатный доступ рассчитан на некоммерческое использование, для коммерческого нужен платный тариф. Ссылка на источник показывается в панели.
- Данные из этих API считаются недоверенными: в страницу они попадают только как текст, а ссылки проверяются.

## 6. Ключ NASA (api.nasa.gov)
Ключ в файлах сайта не хранится. Запросы идут через прокси `nasa.js` (на Netlify он должен лежать в `netlify/functions/`), который читает ключ из переменной окружения.
1. Netlify → *Site configuration → Environment variables* → добавьте `NASA_API_KEY` со своим ключом.
2. Разверните сайт на Netlify вместе с папкой `netlify/` и файлом `netlify.toml` (сайт, загруженный перетаскиванием папки, функции не запускает: нужен деплой из Git или Netlify CLI).
3. Прокси разрешает только четыре заранее заданных запроса (вспышки, выбросы плазмы, магнитные бури, снимок EPIC), поэтому через него нельзя использовать ключ для чего-то другого.
На GitHub Pages функции не работают: карточка «Космос сейчас» покажет сообщение, остальной сайт работает.
Лимит ключа NASA ограничен (около 1000 запросов в час), ответы кешируются на 5–10 минут.
Раз ключ был отправлен в переписке, его лучше перевыпустить на api.nasa.gov и вписать новый в Netlify.

## 7. Запуск и проверка (обновлено)
- Не открывайте `index.html` двойным щелчком: запустите `python3 -m http.server` в папке сайта и откройте `http://localhost:8000`.
- `boot.js` грузит three.js по порядку: локальный файл, cdnjs с хешем, jsDelivr с хешем, затем те же CDN без хеша (флаг `ALLOW_UNVERIFIED = true`). Положите `three.min.js` рядом (`bash fetch-three.sh`) и поставьте флаг в `false`.
- Все файлы лежат в одной папке. Для прокси NASA на Netlify файл `nasa.js` нужно положить в `netlify/functions/nasa.js` (Netlify запускает функции только из отдельной папки). Без этого карточка «Космос сейчас» покажет сообщение, остальной сайт работает.
- Год 2026 в `globe.js`: `a: 1.27, ap: true` (среднее за январь–октябрь по GISS). Когда NASA выпустит итог года (обычно в середине января), замените на точное значение и уберите `ap: true`.
